# Adaptive artwork v2 compatibility note

Selected September 11, 2026. This additive preview assigns new stable schema IDs and leaves every v1 schema and accepted asset unchanged. The capability header `X-Patternlike-Portrait-Protocol: v2` negotiates compatible reads and claims; it does not grant consent. Missing headers retain v1. Terminal versions must match the stored job protocol and lease.

Counts are frozen from the source at reservation and limited to 3, 4, 5 or 6. Every index and chapter ID binds to that count and exact document revision. One-time and automation policy 2.0.0 are separate grants; historical grants retain their original four-chapter scope. The default-off adaptive producer switch gates only new reservations.

Each chapter retains its existing 84-star graph ceiling, three image-job attempts and three mesh-job attempts and bounded per-job geometry/transport/visual inspection budgets. Six chapters permit 1.5 times the image/model jobs of four; three permit 0.75 times and five 1.25 times. Four mesh audit views, RGBA channels, sample dimensions and material limits stay unchanged.

Runtime checks enforce digest/revision joins, exact source attribution, graph connectivity and vertex-array lengths, ordered complete chapter/model/reference sets, program topology and aggregate geometry budgets. JSON Schema cannot express every runtime equality. No deployment, production migration, provider generation or runner installation is established by these artifacts. Rollback must keep a v2-compatible reader, cancellation and cleanup service.

# Offline Pattern writer guidance 1.0.4

Date: 2026-09-11. Implements the [independent AI review follow-ups](../2026-09-11-ai-review/README.md) through an explicit offline request-builder selection. Existing production writer 1.0.3, planner/verifier instructions, old correction instructions, corpus candidates and retained outputs remain unchanged.

`buildPatternResponsesRequest` selects the new instructions only for the writer pass with `writer_prompt_version: "1.0.4"`. The deployed configuration still requires 1.0.3 and refuses 1.0.4. The builder is pure: this change performs no provider call, generation, candidate activation or saved-reading rewrite. Normal and correction variants share the additional editorial guidance. This is a future Pattern writer version, separate from Daily feedback prompt versions.

The guidance preserves uncertainty beside the qualified claim, avoids unsupported mechanisms, labels practical suggestions as optional examples, names only supplied permitted features in cited prose, distinguishes calculation from interpretation, and gives sections/tensions/resources/counter-expressions distinct explanatory jobs. Existing word, chapter, citation, suppression and safety constraints remain in force. Adding “may” is not a substitute for evidence. A prompt instruction does not prove that generated prose follows it or improves reader outcomes.

Planner/verifier selection is unchanged, and production configuration rejects the offline version. The existing creation-source fingerprint must be refreshed for this source change. Further evaluation should use the same bound inputs, retain rejections, include presently missing approximate-time prose, and preserve independent review disagreements.
